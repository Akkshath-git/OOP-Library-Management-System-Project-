# Coursera OOP Library Management System

## 📌 Project Description
This is a Library Management System built using C++ and Object-Oriented Programming concepts as part of my Coursera coursework.

## 🚀 Features
- Add new books
- Remove books
- Search books
- Issue books to members
- Return books
- Manage library records

## 🧠 Concepts Used
- Classes and Objects
- Encapsulation
- Abstraction
- Inheritance
- Polymorphism
- File Handling (if used)

## 🛠️ Tech Stack
- C++
- Object-Oriented Programming (OOP)
- STL (if used)

## ▶️ How to Run
1. Compile the code:
   g++ main.cpp -o library

2. Run the program:
   ./library
